## Testing notes
- **Dev server port drift:** if 3000 is in use, `next dev` silently moves to 3001 —
  check `/tmp` devserver log for the actual port before hitting APIs / injecting cookies.
- **Playwright module is CommonJS:** `import pkg from ".../playwright/index.js"; const { chromium } = pkg;`
- **Playwright `getByRole("button", { name: /Next/ })` matches Next.js devtools button** in
  dev — use `{ exact: true }` to avoid strict-mode violations.
- Auth login: create user with app's `bcryptjs` hash, then NextAuth credentials flow via
  curl (`/api/auth/csrf` → `/api/auth/callback/credentials`), grab `next-auth.session-token`.
