## Testing / infra notes (carry forward)
- No test framework; verification = `tsc --noEmit --skipLibCheck` + `next build`
  + Playwright driving `http://localhost:<port>` with an injected
  `next-auth.session-token` cookie.
- **Dev-server stale cache**: rapidly restarting `next dev` can serve stale JS;
  a full `pkill` + `rm -rf .next` (or a prod `next build`) is the source of truth.
- **Scroll-scrubbed scenes**: screenshots must drive scroll to a scene's local
  pin progress; global-% sampling lands between scenes and looks empty.
- Playwright `getByRole("button",{name:/Next/})` matches Next.js devtools —
  use `{exact:true}`.
- localStorage seeds (classes/calendars) must use `ctx.addInitScript` so they
  persist across navigations in the test.
- Secrets: `.env`, `.env.local`, `*.db` are gitignored; `.claude/` too.
